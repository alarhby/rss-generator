Quick Start Guide

  1. Create a Feed: Click "Create Feed" and enter the URL of the website you want to convert.
  2. Configure Selectors: Define XPath or CSS selectors to extract titles, links, descriptions, and more.
  3. Preview: Use the preview feature to test your configuration and see extracted items.
  4. Generate Feed: Save your configuration and get a unique RSS feed URL.
  5. Subscribe: Use the RSS URL in your favorite RSS reader to start receiving updates.
